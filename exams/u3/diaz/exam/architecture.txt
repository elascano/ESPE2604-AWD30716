1. Backend

Abre una terminal dentro de la carpeta backend

cd backend

Instala las dependencias (solo la primera vez):

npm install

Si aún no las has instalado:

npm install express cors

Si instalaste nodemon:

npm install --save-dev nodemon

Inicia el servidor:

Con Node:
node server.js


Si todo está bien verás:

Server running on port 3006
2. Frontend

Abre la carpeta frontend con Visual Studio Code.

Instala la extensión Live Server (si no la tienes).

Luego:

Clic derecho sobre index.html.
Open with Live Server.

Se abrirá:

http://localhost:5500/
3. Probar la API
Agregar un producto

En Postman:

POST
http://localhost:3006/api/products

Body → Raw → JSON

{
    "id":1,
    "name":"Milk",
    "price":2.5,
    "expiration":{
        "day":15,
        "month":8,
        "year":2026
    }
}

Debe responder:

{
    "message":"Product added successfully",
    "product":{
        "id":1,
        "name":"Milk",
        "price":2.5
    }
}
Ver productos
GET
http://localhost:3006/api/products
Total
GET
http://localhost:3006/api/products/total

http://localhost:3006/api/products/1/iva
