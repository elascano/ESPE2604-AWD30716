Demo: Non-blocking programming & Functional programming

1. View Menu — Non-blocking execution

The client requests the menu from the backend with an asynchronous query (Promise). To verify that the server remains free while it "queries the database", we fire 3 "pings" at almost the same time. Compare the response times.

2. Cart — State immutability

When adding a product, cart.push(item) is never used. A new copy of the array is generated with the spread operator (cart = [...cart, item]), avoiding direct mutations.

  • Empty cart

3. Order total — Pure function

The total is calculated with reduce(): a higher-order, pure, and deterministic function. Same input data, same result always; it does not depend on or modify anything outside of it.
